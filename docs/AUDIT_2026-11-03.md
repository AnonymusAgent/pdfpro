# Independent application audit — 2026-11-03

This audit examined API ownership, authentication/administrator access, billing integration, cloud storage, document processing and browser workflows separately. A successful build or a rendered page alone was **not** treated as proof of correct behavior. Changes in this audit are additive and preserve existing database rows.

## Confirmed defects repaired

- **Cross-user workspace data exposure:** `/api/documents`, `/api/signatures`, `/api/jobs` and `/api/settings` used global data. They now use an authenticated user ID or an opaque HttpOnly guest cookie. Mutations validate ownership and origin. Migration `0003_private_workspace.sql` keeps all old unscoped records under `legacy` (not deleted or exposed to new visitors) and moves old preferences to a separate private table. Existing `settings` used for administrator billing/ads is not repurposed.
- **Cloud objects unreadable after storage-driver switch:** downloads and deletion now select the driver saved on each file record rather than the current deployment default. Preserve the old local directory and any S3 credentials during a migration; switching between two different S3 buckets still requires an operator-led object migration because old rows do not record their bucket. A regression test exercises access to old local files when S3 is configured.
- **Signed download survives account suspension:** download links now verify that the owning account is still active, even without a browser session. Regression-tested over HTTP.
- **PDF magic header split across streaming chunks:** validation now accumulates the first five bytes without discarding any part of the upload; split-header and invalid-header tests cover the stream.
- **OCR duplicate filenames:** selection now reads individual files in order rather than looking them up by name, retaining independent bytes when two inputs share a filename. OCR preview is derived from the selected page rather than duplicated URL state. Unit tests cover duplicate names, unsupported files and read failures.
- **Malformed pagination values:** invalid/fractional values are normalized before database queries across public files and administrator lists; regression-tested over HTTP.
- **Large JSON requests:** the JSON reader enforces its byte limit while streaming rather than buffering an unbounded body. Request parsing rejects arrays/primitives, and personal preference writes validate allowed values. New unit and HTTP tests cover these guards.
- **Editor keyboard handler:** ref assignment moved out of render into an effect; the nested annotation DOM handlers were documented for the hooks linter. Unused lint suppressions in the admin dashboard were removed.
- **Guest metadata abuse:** added per-workspace rate limiting to document creation and preference writes, alongside the existing limits for signatures and jobs.
